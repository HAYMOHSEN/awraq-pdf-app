# Awraq AI Pro Privacy Notice

## What this release processes

When a person selects a PDF, Awraq AI Pro reads and processes that file inside the browser or installed PWA on the person’s device. The release uses local PDF rendering, text extraction, local keyword matching, pattern checks, and local PDF generation for its tools.

## What it does not do

- It does not upload selected PDF files to an Awraq server.
- It does not send PDF text to a cloud AI model.
- It does not create an account or require a sign-in.
- It does not retain copies of selected PDFs in the application history.

## Local history

The app can retain a small activity list in the browser’s local storage. It contains action names, file names, and times only. The person can clear this history from Private History at any time.

## Important limits

The Privacy Pack identifies common patterns for human review. It is not a legal guarantee that a document is free from personal or confidential information. Users should always inspect a redacted document before sharing it.

The public web host and Microsoft Store may independently process normal access, installation, and diagnostics data under their own policies. This notice describes Awraq AI Pro’s document-processing behavior.
